# M2 本地资料库验收记录

验证日期：2026-09-11。运行环境：Node.js 24.19.0、Next.js 16.3.1，生产构建，单用户本机服务。
真实模型接口返回 `deepseek-v4-flash`。本记录只证明下列固定样本结果，不代表全部 18 条完整通过。

## 已交付

- 本机 SQLite 持久化原文件、版本与原文片段；跨连接和服务重启后可读取。
- 上传成功后入库。多文件分别处理，单个失败不丢弃其他成功文件；显示逐文件结果。
- 资料列表支持限定问答范围、查看原文、下载原文件、上传新版、逻辑删除。
- 原文预览支持版本切换。新版解析成功后才成为当前版，保留旧版。
- 资料模式检索当前项目的有效最新版；回答使用服务端生成的引用编号，点击打开对应历史版本及片段。
- 资料模式不使用个人记忆和历史模型答案作证据。无检索结果、模型表示无依据、引用编号无效时保守返回无依据提示。
- 更新或删除导致本轮证据过期时，拒绝返回旧证据答案，提示重试。
- 文档正文不再自动写入个人候选记忆。

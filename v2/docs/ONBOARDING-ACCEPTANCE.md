# 双入口与本机保存验收

日期：2026-09-13。此增量不等于完成 OCR、语义检索、多用户权限等后续里程碑。

## 已交付

- 首页明确区分“问我的资料”和“继续我的项目”，给出用途、下一步和可直接点击的问题示例。
- 独立对话固定用途，防止资料证据模式与个人背景模式在多轮中隐式混用。
- 最近 100 段历史对话入口、刷新恢复当前会话、服务端历史参与多轮问答。
- 问题先落盘，回答、模型名、原文引用和所用记忆随后保存；同一请求成功后重复交付不重复调用模型。
- 单段对话生成期间阻止并发写入；模型失败保留问题，进程中断超过 150 秒后允许重新发送。
- 默认 SQLite 保存记忆、候选、事件、版本和上下文快照；生命周期操作失败不提交部分修改，并发写入通过修订号避免覆盖。
- 窄窗口采用独立聊天滚动区，输入框不随长历史移出视口。

## 验证方法

- `pnpm typecheck`、`pnpm test`、`pnpm build`。
- `node scripts/check-onboarding.mjs`：专门启动/重启两次 Next 生产进程，使用临时数据库和模拟模型。验证输入先保存、引用恢复、服务端历史替代伪造客户端历史、模式/项目过滤、模型失败和重试。测试数据与用户库隔离。
- `node scripts/check-m2.mjs http://127.0.0.1:3317`：真实已配置模型下的 12 组资料功能回归通过，包含导入、跨资料引用、无答案、追问、冲突、更新、删除和基础注入样本。并非通用模型正确性保证。
- 浏览器已检查首页入口、历史对话恢复、刷新后保留 8 条消息、点击历史引用打开对应原文片段。

## 升级保护

旧服务已停止，但原浏览器仍留有数据。从页面可见内容恢复 8 条消息、3 处引用和 1 条新增已确认记忆，补存为“升级前的对话”。引用逐一匹配本机已有文档的名称、版本、片段序号和原文前缀。不重新调用模型，不覆盖原文件。
原始对话时间不可恢复，导入时间仅代表补存时间；旧进程中未显示在页面上的数据未做完整恢复声明。本机备份 `.data/legacy-page-backup.json` 保留，受 Git 忽略。

## 边界

本机单用户，不提供身份认证或跨设备同步。未发送草稿不持久化；尚无对话搜索、删除/导出 UI。历史回答仍保留旧文字，后续提问使用当前有效资料，删除资料不自动擦除历史聊天。记忆快照适用于当前个人规模，未做大量数据或多用户压测。PostgreSQL 记忆模式仍可选，但切换存储不会自动迁移。调用 AI 会发送本轮需要的资料/上下文给所配置的服务。

备份：停止服务后复制整个 `.data`，配置文件单独安全备份，均不要提交 Git。
